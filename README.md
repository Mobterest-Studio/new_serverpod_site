# New Serverpod dashboard

Generated by Dartform from `new_serverpod`. A static site: no build step, no
libraries, nothing loaded from other sites. It reads
`https://new-serverpod.onrender.com` through the project's read-only dashboard routes.

## Put it online (Render, free)

1. Push this folder to its own GitHub repository.
2. In Render: **+ New → Static Site**, choose the repository.
3. Leave **Build Command** empty and set **Publish Directory** to `.`.

## The dashboard key

Viewers enter the dashboard key once; it's kept in their browser. It's the
backend's `SERVERPOD_PASSWORD_dashboardKey`. Copy or change it in Dartform's Deployment tab.

## Files

- `config.js`: this dashboard's settings (tables, labels, colours, backend).
- `index.html`, `app.js`, `styles.css`: the template.
- `Urbanist.ttf`: the font ([SIL Open Font License](Urbanist-OFL.txt)).

Regenerating from Dartform rewrites these files.
